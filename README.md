Telegram Anti-Spam Bot

Описание проекта

Этот проект представляет собой антиспам-бота для Telegram, использующего нейросетевую модель на основе BERT для детекции спама. Бот анализирует текстовые сообщения и определяет, являются ли они спамом или нет.

Возможности

Классификация сообщений как "спам" или "не спам"

Обучение модели на основе предобученного DeepPavlov/rubert-base-cased

Работа с Telegram API

Поддержка GPU для ускоренного обучения

Автоматическое удаление спам-сообщений

Блокировка пользователей при обнаружении ссылок в спам-сообщениях

Отправка сообщений во все чаты, где установлен бот

Установка и запуск

1. Клонирование репозитория

git clone https://github.com/se2112/telegram-antispam-bot.git  
cd telegram-antispam-bot  

2. Установка зависимостей

pip install -r requirements.txt  

3. Запуск бота

python bot_telegram.py

Удаление спам-сообщений и блокировка пользователей

Бот автоматически анализирует все сообщения в чате. Если сообщение определяется как спам, оно удаляется. Если сообщение содержит ссылки и классифицируется как спам, пользователь блокируется.

Принцип работы:

Бот анализирует текст сообщения.

Если сообщение является спамом, оно удаляется.

Если в спам-сообщении обнаружена ссылка, пользователь блокируется.

Бот отправляет предупреждение в чат и через 60 секунд удаляет его.

Отправка сообщений во все чаты

Бот поддерживает функцию массовой рассылки сообщений во все чаты, где он установлен. Для этого используется команда:

/broadcast [текст сообщения]

Доступ к команде имеет только администратор бота. После выполнения команды бот отправит сообщение во все чаты, где он используется.

Проверка работы бота

Для проверки работы бота установите @addictedNadya_bot в качестве администратора в чат и предоставьте доступ к сообщениям.
